#
# HTTP-01 (resolver "le") cannot issue *.handson.tools. Without this resolver,
# Traefik serves the default certificate (ORCA) for those names — before any
# HTTP redirect to handson.tools can run.
#
# Keep resolver "le" for OpenProject and known Host() names.
# Add resolver "le-dns" to the existing Traefik compose, then:
#   docker compose up -d traefik
#
# Token must create/delete TXT _acme-challenge.handson.tools.
